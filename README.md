# What is EarlyCareering?

EarlyCareering is a job tracker that allows for user to do basic job/internship application tracking and keep track of all the jobs they've applied to.

First, users are required to create an account with us where they provide basic information such as an username, email, password, and career journey status (e.g. college student, entry-level, mid-level, senior).

- F.Y.I: The password must contain a number and uppercase letter to work and they must reenter the password in order for it to work. (We will try to see if password manager will pick it up to make it easy for users.)

After this, users can fill out their worker profile with their skills, job summary, work experience, and etc. to help the job tracker's AI accurately evaluate you as a candidate.

When user adds a job that they applied to, they must add basic information such as job title and description and the company's name. After entering the required info, users can provide addtional information such as the priority (e.g. main, medium, low(stretch)), application date, motivation(s) for wanting the job.

After adding a job, the user can call an AI API such as gemini or chatgpt to breakdown the job description to describe what is needed, view any motivation if there is any, and see where you are at in the career journey (e.g. senior) in order to access the job fit.

# Inspiration for Project

I was motivated to create this project after going through internship and job search. I love Linkedin's Job Tracking feature and I felt that it was very helpful. However, I dislike how you could only track jobs that you applied to via Linkedin. You couldn't track jobs that you applied to in other platforms nor could you track jobs that you applied to on the company's website. This job tracker will allow you to track applications no matter where you applied at.

Another thing about this job tracker is that it provides a free alternative to Linkedin's Premium and premium AI plans. With Linkedin premium, you get AI-powered job insights that tells you whether a job is a good fit for you or not based on your job profile. You may also want to leverage paid AI tools like ChatGPT or Gemini to help you with further evaluation on if a job is a good fit. My project provides all of this for FREE! You will get access to AI-Powered features that will allow you to accurately evaluate whether a job is a good fit or not without having to contribute a single dollar!
